# PocketPaths

Turn a dense set of instructions into connected cards, then focus on one step and resume where you left off.

The demo works in the browser with no account and no AI API key. Paths, progress, and accessibility settings are saved in `localStorage`.

## Run

```bash
npm install
npm run dev
```

## Demo

1. Choose **Try the sample** or **Create a path**, then **Load sample**.
2. Choose **Organize**, correct any card, then **Create path**.
3. Switch between Cards, Map, and Steps.
4. Choose **Focus**, then **Mark complete**.
5. Refresh the page. The same step comes back.
6. Edit a card, then **Undo**.
7. Open **Settings** and change text size, contrast, or read aloud.
